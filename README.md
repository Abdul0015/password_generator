# 🔐 Password Generator

A simple and interactive **Password Generator** built using HTML, CSS, and JavaScript. This project allows users to generate random passwords by customizing their password length and choosing which types of characters to include.

Created as a learning project to practice web development fundamentals, DOM manipulation, and JavaScript event handling.

## ✨ Features

- **Custom Password Length:** Choose a password length between 4 and 24 characters.
- **Lowercase Letters:** Include letters from `a-z`.
- **Uppercase Letters:** Include letters from `A-Z`.
- **Numbers:** Include digits from `0-9`.
- **Special Characters:** Include symbols such as `!@#$%^&*`.
- **One-Click Generation:** Generate a new password with a button click.
- **Copy to Clipboard:** Copy the generated password with a single click.
- **Interactive Interface:** Passwords update when you change the length or character options.
- **Simple UI:** Clean layout with CSS styling.

## 🛠️ Technologies Used

- **HTML5** — Structure of the application.
- **CSS3** — Styling and layout.
- **JavaScript** — Password generation, user interaction, and clipboard functionality.

## 📸 How It Works

1. Choose the desired password length using the slider.
2. Select the character types you want to include:
   - Lowercase letters (`a-z`)
   - Uppercase letters (`A-Z`)
   - Numbers (`0-9`)
   - Special characters (`!@#$%^&*`)
3. Click the **Generate** button to create a password.
4. Click **Copy** to copy the generated password to your clipboard.

## 🚀 Getting Started

No installation or additional libraries are required.

### Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/Abdul0015/password_generator.git
```

**2. Navigate to the project directory**

```bash
cd password_generator
```

**3. Open the application**

Open `index.html` in your web browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension.
